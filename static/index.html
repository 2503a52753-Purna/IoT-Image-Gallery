Cloud Computing Architecture & AWS Deployment Specification

Product Architecture: IoT Image Gallery

This software satisfies all requirements of the Cloud Computing problem statement:

  • Press a button to capture an event: Physical tactile push button (GPIO 14) and keyboard trigger, recording camera frame & sensor telemetry.
  • An LED confirms upload: Real-time hardware LED state machine (GPIO 27) transitions from Capturing & Uploading to solid bright Green Confirmation upon cloud receipt.
  • Image auto thumbnail via Lambda: Serverless event-driven architecture invokes an AWS Lambda function upon S3 PutObject, resizing the image via Pillow with high compression efficiency.

AWS Cloud Native Components

Component AWS Service Function / Role
Edge Camera Node AWS IoT Core / HTTP Gateway Captures image event on button trigger, controls status LED.
Raw Bucket Amazon S3 (Raw Storage) Stores full-resolution capture; emits S3:ObjectCreated.
Auto Thumbnailer AWS Lambda (Python 3.12) Serverless resizer triggered automatically by S3 event.
Thumbnails Bucket Amazon S3 (Thumbnails) Optimized thumbnails served to the Image Gallery.

If you haven't created your S3 buckets or Lambda function yet, this repository includes an Automated Provisioner script that will do everything for you in under 60 seconds:

  • Validates your AWS IAM credentials via AWS STS
  • Creates globally-unique S3 Raw and Thumbnails buckets with CORS
  • Creates the IAM Execution Role for AWS Lambda
  • Downloads the Linux Pillow wheel and packages lambda_function.py
  • Deploys the AWS Lambda function to your region
  • Configures the S3 ObjectCreated event trigger to invoke Lambda
  • Automatically writes all parameters to .env and activates live mode

How to get your AWS Access Keys:

  1. Log in to the AWS Management Console (console.aws.amazon.com).
  2. Go to IAM (Identity and Access Management) → Users.
  3. Click your IAM User (or create one, e.g., iot-gallery-admin).
  4. Under the Security credentials tab, scroll down to Access keys and click Create access key.
  5. Select Command Line Interface (CLI) or Local code and download your Access Key ID and Secret Access Key.

Required IAM Permissions:

For full automated provisioning and execution, your IAM user needs policies covering:

Amazon S3:
s3:CreateBucket, s3:PutObject, s3:GetObject, s3:PutBucketNotification, s3:PutBucketCors
AWS Lambda:
lambda:CreateFunction, lambda:UpdateFunctionCode, lambda:InvokeFunction, lambda:AddPermission
IAM Roles:
iam:CreateRole, iam:PutRolePolicy, iam:PassRole
AWS STS:
sts:GetCallerIdentity

Tip: In an AWS Academy or personal sandbox account, the AdministratorAccess or PowerUserAccess policy gives all necessary permissions.
